This paper proposes a new contact planner for gaited locomotion. The main contribution is that we relax the non-linear problem of selecting the appropriate contact surface for an effector into a convex one using L1-norm minimization. This results in an efficient planner, implemented in only 200 lines of python code.

Read the [paper]({{ '/assets/pdf/tonneau2020sl1m.pdf' | relative_url }}) or watch the [video](https://youtu.be/gOQHI-YlOi0). See also the [project page](/projects/sl1m/).
